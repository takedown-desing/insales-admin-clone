# Копия админки InSales

Рабочий прототип интерфейса админ-панели InSales, собранный для услуги переноса магазинов
с платформы на обычный хостинг.

- **`index.html`** — сама админка, 51 экран.
- **`report.html`** — разбор платформы: карта разделов, модель данных, каналы выгрузки магазина.

## Откуда взяты интерфейс и данные

Всё снято с живого триал-магазина InSales 23 августа 2026 года: 150 страниц админки,
137 скриншотов, 22 эндпоинта API с реальными ответами.

Стили не подбирались на глаз — сняты вычисленные значения с работающей панели:

| Параметр | Значение оригинала |
|---|---|
| Шрифт оболочки | Golos Text |
| Шрифт контента | MuseoSans |
| Фон сайдбара | `#2B3B4C` |
| Акцент | `#3d8bf4` |
| Пункт меню | 36px, радиус 4px, отступ 12px, подпункт 48px |

Наполнение тоже настоящее: девять страниц оригинала с их адресами, четыре статьи блога,
пять меню с двадцатью пунктами — выгружены через API, а не придуманы.

## Две сознательные замены

**Шрифт контента.** В оригинале MuseoSans — коммерческий шрифт, распространять его нельзя.
Взят Mulish: ближайший свободный аналог с кириллицей.

**Логотип.** В шапке стоит текстовая надпись, а не фирменный знак InSales. Воспроизводить
чужой товарный знак в продукте, который эту платформу заменяет, не стоит — при внедрении
у клиента здесь будет его собственный логотип.

## Что работает

Создание, редактирование и удаление по товарам, заказам, клиентам, страницам, блогу, меню
сайта, доставке, оплате, скидкам, складам, группам клиентов. Групповые операции над товарами
с реальными именами маршрутов InSales. Фильтры в каталоге, ценах и заказах — 10, 17 и 7 полей
соответственно. Выгрузка в CSV и JSON, обратная загрузка. Предпросмотр SEO-шаблонов.

Данные хранятся в localStorage браузера.

## Чего нет и почему

GitHub Pages — статический хостинг, сервера и базы здесь нет. Отсюда не работают: загрузка
картинок и файлов, разбор загружаемых CSV и YML, редактор Liquid-шаблонов писем.
Для боевой работы те же экраны подключаются к настоящей базе и к API МойСклада.

Корзина, оформление заказа покупателем, эквайринг и онлайн-касса по 54-ФЗ не входят
в прототип — это отдельный пласт работы, который надо обсуждать до оценки сроков переноса.

Разделы, которые договорились не переносить — аналитика, диалоги, маркетплейсы, продвижение —
оставлены заглушками с объяснением.
