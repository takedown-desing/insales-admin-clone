# Копия админки InSales

Рабочий прототип интерфейса админ-панели InSales, собранный для услуги переноса магазинов
с платформы на обычный хостинг.

- **`index.html`** — сама админка. Каталог, заказы, клиенты, цены и остатки, страницы, блог,
  доставка, оплата, скидки, домены, счётчики, SEO-шаблоны, robots.txt, редиректы,
  пользовательские статусы, оформление заказа. Создание, редактирование и удаление работают,
  данные лежат в localStorage браузера.
- **`report.html`** — разбор платформы: карта из 53 разделов, модель данных на 13 сущностей,
  проверенные каналы выгрузки магазина клиента.

Интерфейс, названия полей и структура данных сняты с живого триал-магазина InSales
23 августа 2026 года: 150 страниц админки, 137 скриншотов, 22 эндпоинта API с реальными
ответами.

## Что это не умеет

GitHub Pages — статический хостинг, сервера и базы здесь нет. Данные живут в браузере
и не синхронизируются между устройствами. Для боевой работы нужен бэкенд: тогда те же
экраны подключаются к настоящей базе и к API МойСклада.

Корзина, оформление заказа покупателем, эквайринг и онлайн-касса по 54-ФЗ не входят
в этот прототип — это отдельный пласт работы, который надо обсуждать до оценки сроков.
